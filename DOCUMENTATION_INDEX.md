## 🗂️ File Locations

### Components

All React components are in `src/components/`:

- `Navbar.jsx` - Navigation bar with scroll detection
- `Hero.jsx` - Hero section with CTAs
- `Services.jsx` - Services grid
- `ProductCard.jsx` - Individual product card
- `Products.jsx` - Product grid container
- `Footer.jsx` - Footer section

### Main Files

- `src/app/page.js` - Main page (imports all components)
- `src/app/layout.js` - Root layout (metadata, fonts)
- `src/app/globals.css` - Global styles

### Configuration

- `package.json` - Dependencies
- `next.config.mjs` - Next.js configuration
- `tailwind.config.mjs` - Tailwind CSS configuration
- `jsconfig.json` - JavaScript paths
